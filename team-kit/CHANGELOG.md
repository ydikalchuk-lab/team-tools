# Changelog

All notable changes to the team-kit plugin are documented here.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.1] - 2026-08-03

### Added

- Plugin `README.md` documenting the two skills, installation, and layout.
- Root marketplace `README.md` for the team-tools repository.
- `marketplace.json` registering team-kit so the team can install it via
  `/plugin marketplace add`.

## [1.0.0] - 2026-08-03

### Added

- Initial release with two skills:
  - `commit-changes` — multi-repo Conventional Commits workflow.
  - `prompt-improve` — turns a raw task draft into a structured prompt.
